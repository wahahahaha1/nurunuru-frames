NuruNuru Frames
================

YouTube とニコニコ動画を、ブラウザ内（WebGPU）で動き補償フレーム補間し、
ディスプレイのリフレッシュレート（120Hz / 144Hz / 180Hz など）でなめらかに再生する拡張機能です。
ページの UI、コメント、全画面などはそのまま使えます。

動作環境
--------
- Chrome / Edge / Vivaldi などの Chromium 系ブラウザ（バージョン 116 以降）で、WebGPU が使えること
  （アドレスバーに chrome://gpu または vivaldi://gpu を入力し、「WebGPU: Hardware accelerated」と出ていれば使えます）
- 単体 GPU を推奨します。GPU の負荷が高すぎる場合は、自動で画質を下げ、それでも足りなければ補間を止めます
- 動画の fps がモニターのリフレッシュレートに近い場合（60Hz のモニターで 60fps の動画など）は補間せず、そのまま再生します

インストール
------------
1. この zip を好きな場所に展開します（manifest.json が入っているフォルダごと残しておいてください）
2. ブラウザで拡張機能の管理ページを開きます
   Chrome: chrome://extensions   Edge: edge://extensions   Vivaldi: vivaldi://extensions
3. 「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダ（manifest.json があるフォルダ）を選びます

使い方
------
- 動画を再生すると自動で補間が始まります
- Alt+Shift+S で ON/OFF、Alt+Shift+D で比較表示（左: 元映像 / 右: 補間）を切り替えます
- ツールバーのアイコン（青い再生マーク）から、目標フレームレートや画質プリセットを設定できます
  目標フレームレートは「ディスプレイに合わせる」「ソースの 2 / 2.5 / 3 倍」「固定値」から選べます。
  モニターの Hz を割り切れる値（144Hz なら 144 / 72 / 48、180Hz なら 180 / 90 / 60）が最もなめらかです
- 補間には約 1 フレームの遅延があります。口の動きと音のずれが気になる場合は、
  設定の「音ズレ補正（実験的）」をオンにしてください（ページを一度クリックすると有効になります）

できないこと
------------
- DRM で保護された動画（有料映画など）は補間しません（元の映像のまま表示します）
- 動画のダウンロード、広告の除去、データの収集・送信は一切行いません
