# NuruNuru Frames

YouTube とニコニコ動画を **ブラウザの中で** フレーム補間し、ディスプレイのリフレッシュレート（例: 144Hz / 180Hz）でぬるぬる再生する拡張機能です。
ブロックマッチングによる動き推定と動き補償（SVP などの補間ソフトと同じ考え方）を、WebGPU で GPU 上に実装しています。

- ページはそのまま使えます。コメント、操作 UI、シアターモード、全画面、ログイン状態もそのままです（ニコニコのコメントは補間映像の上に表示されます）
- 24/30/60fps の動画を、表示 Hz または指定した目標フレームレートまで補間します
- GPU の負荷を自分で測り、重すぎるときは自動で画質を下げます（それでも足りなければ補間を止めます）
- 動画のダウンロード、広告の除去、データの収集・送信は一切行いません

## ダウンロード

[Releases](../../releases) から `nurunuru-frames-<バージョン>.zip` をダウンロードしてください。

## 用意するもの

- Chromium 系のブラウザ（Vivaldi / Chrome / Edge、バージョン 116 以降）
- WebGPU が使える GPU（単体 GPU を推奨）。アドレスバーに `vivaldi://gpu`（Chrome は `chrome://gpu`）と入力し、**WebGPU: Hardware accelerated** と出ていれば使えます
- 表示 Hz の高いモニター（120Hz 以上）だと効果が大きくなります。60Hz のモニターでは 60fps 未満の動画が対象です（60fps の動画はそのまま再生します）

## インストール

1. ダウンロードした zip を好きな場所に展開します。`manifest.json` が入っているフォルダは、使っている間は消さずに残しておいてください
2. アドレスバーに `vivaldi://extensions`（Chrome は `chrome://extensions`、Edge は `edge://extensions`）と入力して開きます
3. 右上の **デベロッパーモード** をオンにします
4. **「パッケージ化されていない拡張機能を読み込む」** を押し、展開したフォルダ（`manifest.json` があるフォルダ）を選びます
5. ツールバーに出る「NuruNuru Frames」アイコン（青い再生マーク）から設定を開けます

新しいバージョンにするときは、フォルダの中身を入れ替えてから、拡張機能の管理ページで ↻（再読み込み）を押し、動画ページを再読み込みしてください。

## 使い方

YouTube（`www.youtube.com`、埋め込み）やニコニコ動画（`www.nicovideo.jp`、生放送、埋め込み）で動画を再生すると、自動で補間が始まります。

| ショートカット | 動作 |
| --- | --- |
| `Alt+Shift+S` | 補間の ON / OFF |
| `Alt+Shift+D` | デモ表示（左: 元映像 / 右: 補間）の切り替え |

ショートカットは `vivaldi://extensions/shortcuts`（Chrome は `chrome://extensions/shortcuts`）で変更できます。

### ポップアップの設定

| 項目 | 内容 |
| --- | --- |
| 有効（右上スイッチ） / サイト別 | 全体、または YouTube／ニコニコごとの ON / OFF |
| 目標フレームレート | ディスプレイに合わせる（既定）／ソースの 2・2.5・3 倍／固定値（任意の fps）。表示 Hz を割り切れる値（180Hz なら 180 / 90 / 60 / 45）は全フレームが同じ時間ずつ表示されて最もなめらかです。割り切れない値（180Hz で 144 など）は等間隔の時刻で補間しますが、画面の更新に合わせるため 1 フレームの表示時間が 1〜2 回分で不揃いになります |
| 画質プリセット | 速度優先（動き推定 幅 640）／標準（960）／高画質（1280、1/4 画素精度）。SVP の coarse width に相当します |
| アーティファクトマスキング | 動きベクトルが怪しい場所を、単純ブレンドに寄せて破綻を目立たなくします（SVP の「マスキング」に相当）。0 が最もシャープです |
| シーンチェンジ検出感度 | 高いほどカット切り替えを検出しやすくなります。検出されたフレーム間は補間しません |
| 音ズレ補正 / 音声オフセット | 音声を補間の遅延ぶん遅らせます（実験的、既定はオフ）。ずれが気になるときはオフセットで微調整してください |
| デモ表示 / 動きベクトル表示 / 統計 OSD | 動作確認用 |

ポップアップの状態欄には、ソース fps → 出力 fps、補間率、遅延、GPU 負荷、underrun（次のフレームが間に合わなかった回数）が表示されます。

### GPU 負荷の自動調整

GPU のタイムスタンプで「動き推定（ソース 1 フレームあたり）」と「描画（出力 1 フレームあたり）」の時間を測り、補間が GPU 時間の 70% を 3 秒続けて超えると、次の順で軽くします。

1. 画質プリセットを 1 段下げる（高画質 → 標準 → 速度優先）
2. 出力フレームレートを目標の半分にする
3. 補間を止めて元の映像を表示する（ポップアップでプリセットを選び直すと再試行します）

## 動作の仕組み

1. `requestVideoFrameCallback` で動画の新しいフレームごとに、WebGPU テクスチャへ取り込みます（YouTube／ニコニコは MSE 再生なので読み取りできます）
2. 輝度ピラミッドを作り、階層ブロックマッチング（8px ブロック、重なりあり、前後方向、時間予測、サブピクセル精度、3×3 メディアン）で動きベクトルを求めます
3. ディスプレイの各フレーム（`requestAnimationFrame`）で、ベクトル場を不動点反復で中間時刻に合わせ、前後 2 フレームをワープして、整合性で重み付けしながら合成します。オクルージョンとシーンチェンジも処理します
4. 結果は `<video>` の直後に重ねた canvas に描きます。z 順は動画と同じなので、コメントや UI はその上に表示されます

補間には「次のフレーム」が必要なため、映像は 1 フレーム＋表示 1 フレーム分（30fps / 180Hz なら約 40ms）遅れて表示されます。音ズレ補正はこの遅延に合わせて音声を遅らせます。

## うまくいかないとき

- **補間されない**：ポップアップの状態欄に理由が出ます。「ソース fps ≥ 表示 Hz」「DRM 保護」などの場合は、元の映像のまま再生します
- **WebGPU が利用できません と出る**：`vivaldi://gpu` で WebGPU が無効になっていないか確認してください。リモートデスクトップ経由やハードウェアアクセラレーションをオフにしていると使えません
- **カクつく・重い**：画質プリセットを「速度優先」にするか、目標フレームレートを表示 Hz の半分（180Hz なら 90）にしてください
- **口の動きと音がずれる**：「音ズレ補正（実験的）」をオンにし、必要なら音声オフセットで調整してください
- **元に戻したい**：右上のスイッチか `Alt+Shift+S` でオフにするか、拡張機能の管理ページで無効化・削除してください

## 既知の制約

- **音ズレ補正は、ページを一度クリックするかキー操作した後に有効になります**（ブラウザの自動再生ポリシーのため）。動画の音声を WebAudio 経由に付け替える仕組みなので、そのページを開いている間は元に戻りません（オフにすると遅延 0 になります）
- DRM 付きの動画（YouTube の有料映画など）は補間できません。その場合は自動で元の映像のまま表示します
- ソースの fps が表示 Hz に近い場合（60Hz モニターで 60fps の動画など）は、補間が不要なので何もしません
- HDR 動画は SDR として表示されます。ピクチャーインピクチャーは元の映像のままです
- RIFE などの AI 補間には対応していません
- ブラウザのタブを切り替えると、戻ったときに数フレームだけ元の映像に戻ってから補間を再開します

## 開発・テスト

```
extension/                 拡張機能本体（ビルド不要の素の JS）
  content/engine/          WebGPU エンジン（shaders.js: WGSL、interpolator.js: 取り込み・動き推定・描画）
  content/main.js          再生ループ（rVFC での取り込み、rAF での描画、バイパス判定）
  content/clock.js         メディアクロックと遅延の管理
  content/overlay.js       video に重ねる canvas
  content/audio-sync.js    WebAudio の DelayNode による音声遅延
  popup/                   設定画面
  README.txt               配布用の説明書（zip に同梱）
test/
  make-test-clips.ps1      ffmpeg（SVP 4 同梱のものを参照）で 60fps の合成テスト映像を作る
  harness.html / .js       品質テスト（偶数フレームから奇数フレームを補間して PSNR を比較）と、ローカル動画の補間再生
  cdp.py                   テスト用の一時プロファイルで Vivaldi を起動し、DevTools Protocol で操作する
tools/make_icons.py        アイコン生成
tools/package.py           配布用 zip（dist/nurunuru-frames-<version>.zip）を作る
```

品質テストの実行例:

```
powershell -File test\make-test-clips.ps1
py -3.10 -E -m http.server 8765 --bind 127.0.0.1
py -3.10 -E test\cdp.py launch
py -3.10 -E test\cdp.py open http://127.0.0.1:8765/test/harness.html
py -3.10 -E test\cdp.py eval harness.html "runQuality().then(r => JSON.stringify(r))"
```

RTX 3080 での測定結果（標準プリセット、t=0.5 の PSNR、単純ブレンドとの比較）:

| パン | 33.9 dB | 17.6 dB | +16.3 dB |
| 高速パン | 33.7 dB | 18.0 dB | +15.8 dB |
| 動く物体（オクルージョン） | 30.7 dB | 21.2 dB | +9.5 dB |
| ズーム | 33.6 dB | 29.1 dB | +4.5 dB |
| testsrc2 | 31.3 dB | 26.5 dB | +4.8 dB |
